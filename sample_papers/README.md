# Sample Academic Research Papers

This directory contains information on test research papers suitable for testing PaperMind AI.

You can place open-access research papers here (e.g., from arXiv) to test the application.

## Recommended Open Access Sample Papers:
1. **"Attention Is All You Need"** (Vaswani et al., 2017)
   - arXiv: https://arxiv.org/abs/1706.03762
   - Good benchmark for Transformer architecture, multi-head attention, BLEU scores.

2. **"BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding"** (Devlin et al., 2018)
   - arXiv: https://arxiv.org/abs/1810.04805
   - Good benchmark for masked language models and GLUE benchmarks.

3. **"Deep Residual Learning for Image Recognition"** (He et al., 2015)
   - arXiv: https://arxiv.org/abs/1512.03385
   - Good benchmark for computer vision and residual connections.
